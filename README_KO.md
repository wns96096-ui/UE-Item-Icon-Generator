# 아이템 아이콘 생성기 사용설명서

아이템 아이콘 생성기는 스태틱 메시를 별도의 프리뷰 씬에서 촬영하여 `Texture2D` 아이콘으로 저장하는 Unreal Engine 에디터 플러그인입니다. 여러 메시를 목록에 추가해 순차적으로 생성할 수 있으며, 메시마다 구도와 조명을 따로 조정할 수 있습니다.

> 이미지 삽입 위치 1 — 완성된 아이콘 예시 3~4개

## 1. 설치 및 업데이트

1. Unreal Editor를 종료합니다.
2. 패키징된 플러그인 폴더를 프로젝트의 `Plugins` 폴더에 복사합니다.
3. 최종 구조가 `<프로젝트>/Plugins/ItemIconGenerator/ItemIconGenerator.uplugin` 형태인지 확인합니다.
4. 프로젝트를 열고 플러그인 활성화 또는 모듈 로드 안내가 나오면 승인합니다.
5. 메뉴에서 `도구 > 아이템 아이콘 생성기`를 선택합니다.

업데이트할 때는 에디터를 종료한 뒤 기존 플러그인 폴더를 새 패키지로 교체합니다. 이전 버전의 `Binaries`나 `Intermediate`가 새 버전과 섞이지 않도록 폴더 전체를 교체하는 방식을 권장합니다.

> 이미지 삽입 위치 2 — `도구 > 아이템 아이콘 생성기` 메뉴

## 2. 빠른 사용 순서

1. 콘텐츠 브라우저에서 아이콘으로 만들 스태틱 메시를 하나 이상 선택합니다.
2. 아이템 아이콘 생성기에서 `콘텐츠 브라우저 선택 추가`를 누릅니다.
3. 출력 폴더, 이름 규칙, 해상도와 투명 배경 여부를 설정합니다.
4. 목록에서 메시 하나를 선택하고 미리보기 구도를 조정합니다.
5. 한 개만 저장하려면 `선택 미리보기 저장`, 목록 전체를 처리하려면 `전체 생성`을 누릅니다.
6. 생성된 `Texture2D`를 지정한 출력 폴더에서 확인합니다.

> 이미지 삽입 위치 3 — 메시를 여러 개 선택한 콘텐츠 브라우저

> 이미지 삽입 위치 4 — 메시가 추가된 플러그인 전체 화면

## 3. 목록 관리

- `콘텐츠 브라우저 선택 추가`: 콘텐츠 브라우저에서 선택한 모든 스태틱 메시를 목록에 추가합니다.
- `선택 항목 제거`: 플러그인 목록에서 선택한 행을 제거합니다. 원본 메시 에셋은 삭제되지 않습니다.
- `전체 비우기`: 현재 작업 목록만 비웁니다.
- `사용`: 체크된 항목만 `전체 생성` 대상에 포함됩니다.
- `출력 에셋`: 항목별 저장 이름입니다. 직접 수정할 수 있습니다.
- `상태`: 대기, 준비 중, 생성 중, 저장 완료, 실패 또는 취소 상태를 표시합니다.

같은 메시를 다시 추가하면 기존 항목이 유지되고 중복 항목은 추가되지 않습니다.

## 4. 출력 설정

### 출력 폴더

Unreal 콘텐츠 경로를 입력합니다. 기본값은 `/Game/Generated/ItemIcons`입니다. 운영체제의 디스크 경로가 아니라 `/Game`으로 시작하는 패키지 경로를 사용해야 합니다.

### 이름 규칙

기본값은 `T_Icon_{MeshName}`입니다. `{MeshName}` 부분이 원본 스태틱 메시 이름으로 치환됩니다.

예: `SM_Sword` → `T_Icon_SM_Sword`

목록의 `출력 에셋` 이름을 직접 수정한 항목은 이후 이름 규칙을 바꿔도 사용자 지정 이름이 유지됩니다.

### 해상도

64~4096 범위에서 지정할 수 있으며 기본값은 512입니다. 큰 해상도는 캡처와 저장 시간 및 메모리 사용량을 증가시킵니다.

### 투명 배경

켜면 메시 바깥 영역을 투명 알파로 저장합니다. UI 아이콘 제작에는 일반적으로 켜는 것을 권장합니다.

### 기존 에셋 덮어쓰기

켜면 같은 경로와 이름의 기존 텍스처를 갱신합니다. 끈 상태에서 동일한 에셋이 있으면 해당 항목이 실패할 수 있습니다.

> 이미지 삽입 위치 5 — 출력 폴더, 이름 규칙, 해상도와 체크박스 영역

## 5. 미리보기 조작

목록에서 메시를 선택하면 미리보기가 자동으로 생성됩니다. 설정을 바꾸면 잠시 후 자동 갱신되며, 즉시 다시 만들려면 `새로고침`을 누릅니다.

| 입력 | 동작 |
| --- | --- |
| 마우스 왼쪽 드래그 좌우 | 메시 Yaw 회전 |
| 마우스 왼쪽 드래그 상하 | 메시 Pitch 회전 |
| W / S | 화면 기준 위 / 아래로 구도 이동 |
| A / D | 화면 기준 왼쪽 / 오른쪽으로 구도 이동 |
| 마우스 휠 | 줌인 / 줌아웃 |

드래그 회전은 스태틱 메시의 임포트 피벗을 기준으로 합니다. 피벗이 메시 중심에서 벗어난 에셋은 회전하면서 위치가 크게 움직이는 것처럼 보일 수 있습니다.

WASD는 원본 메시 에셋을 이동하지 않습니다. 카메라가 바라보는 목표점을 옮겨 화면 구도만 변경합니다.

> 이미지 삽입 위치 6 — 미리보기 위에 드래그 방향과 WASD를 표시한 화면

## 6. 공통 설정과 메시별 설정

- `이 메시만 별도 설정`이 꺼져 있으면 선택한 값을 공통 설정으로 편집하며 다른 메시에도 적용됩니다.
- 체크하면 현재 공통 설정을 복사해 선택한 메시만 별도 값을 사용합니다.
- 미리보기에서 드래그, WASD 또는 휠을 사용하면 해당 메시의 별도 설정이 자동으로 활성화됩니다.

여러 메시를 같은 구도와 조명으로 만들려면 공통 설정을 먼저 조정하고, 예외가 필요한 메시만 별도 설정을 사용하면 됩니다.

## 7. 조명과 색 설정

### 키 조명

형태와 주 방향을 결정하는 기본 조명입니다. `키 조명 회전 P/Y/R`로 방향을, `키 / 필 / 백 강도`의 첫 번째 값으로 밝기를 조정합니다.

### 필 조명

키 조명의 반대쪽 어두운 면을 보완합니다. 값이 너무 크면 입체감이 약해질 수 있습니다.

### 백라이트

메시 뒤쪽에서 윤곽을 분리하는 조명입니다. 배경과 색이 비슷한 메시의 실루엣을 강조할 때 유용합니다.

### 스카이 / 노출 / 채도

- 스카이: 전체적으로 들어오는 환경광의 세기입니다.
- 노출: 최종 이미지의 전체 밝기를 보정합니다.
- 채도: `1.0`이 원본이며, `0.0`은 흑백, `2.0`은 채도를 강화합니다.

### 조명색과 배경색

키·필·백 조명색은 각각 R/G/B 0~1 범위로 지정합니다. 배경색은 R/G/B/A를 사용하지만 `투명 배경`이 켜져 있으면 최종 저장 이미지의 메시 바깥 영역은 투명해집니다.

처음에는 흰색 조명을 유지하고 강도와 방향부터 맞춘 다음, 필요한 경우에만 조명색을 조절하는 것이 안정적입니다.

## 8. 저장과 배치 생성

### 선택 미리보기 저장

현재 선택한 메시 한 개를 현재 구도와 출력 설정으로 저장합니다. 개별 메시를 확인하면서 작업할 때 사용합니다.

### 전체 생성

목록에서 `사용`이 체크된 항목을 위에서부터 순차적으로 생성합니다. 한 항목이 실패해도 가능한 다음 항목을 계속 처리합니다.

### 취소

현재 처리 중인 항목이 끝나는 안전한 시점에 남은 작업을 취소합니다.

### 실패 항목 재시도

상태가 `실패`인 항목만 다시 실행합니다. 원인을 수정한 뒤 전체 목록을 다시 만들 필요 없이 사용할 수 있습니다.

> 이미지 삽입 위치 10 — 콘텐츠 브라우저에 생성된 Texture2D 결과

## 9. 권장 작업 방식

1. 대표 메시 하나로 공통 조명과 해상도를 먼저 결정합니다.
2. 전체 메시를 추가하고 미리보기를 빠르게 확인합니다.
3. 피벗이나 비율이 다른 메시만 별도 설정으로 구도를 조정합니다.
4. `기존 에셋 덮어쓰기`를 끈 상태로 첫 배치를 생성합니다.
5. 결과 확인 후 수정 항목만 덮어쓰기 또는 실패 항목 재시도로 갱신합니다.

## 10. 문제 해결

### 메시가 회전하면서 화면 밖으로 움직임

현재 회전 기준은 메시의 임포트 피벗입니다. 원본 메시의 피벗을 정리하거나 WASD로 목표점을 보정합니다.

### 첫 미리보기가 느림

새 프로젝트나 처음 사용하는 머티리얼은 셰이더 컴파일과 텍스처 스트리밍을 완료한 뒤 캡처하므로 첫 표시가 늦을 수 있습니다. 같은 메시의 이후 구도 변경은 재사용된 프리뷰 씬을 사용합니다.

### 메시가 기본 회색 또는 흰색으로 보임

최신 플러그인 버전인지 확인한 뒤 셰이더 컴파일이 끝나면 `새로고침`을 누릅니다. 원본 메시의 머티리얼 슬롯과 머티리얼 컴파일 오류도 함께 확인합니다.

### 저장에 실패함

- 출력 폴더가 `/Game`으로 시작하는지 확인합니다.
- 같은 이름의 에셋이 있다면 `기존 에셋 덮어쓰기`를 켜거나 출력 이름을 바꿉니다.
- 출력 에셋 이름에 경로 구분자나 사용할 수 없는 문자가 없는지 확인합니다.

### 투명 배경이 보이지 않음

텍스처 에디터의 체크무늬 배경에서 알파를 확인합니다. 일반 이미지 뷰어가 투명 영역을 흰색이나 검은색으로 표시할 수도 있습니다.
